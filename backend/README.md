# Backend (Laravel API)

## Purpose
The backend is the core of the Hotel Management System. It provides a RESTful JSON API that powers the Admin UI and the Guest‑facing Frontend UI.

## Tech Stack
- **Framework**: Laravel 9.x (PHP 8.2)
- **Database**: MySQL 8.0 (or MariaDB)
- **Auth**: Laravel Sanctum (SPA token) + JWT fallback
- **Queue**: Redis (default Laravel queue driver)
- **Mail**: Laravel Mail (configurable via SMTP, SendGrid, Mailgun)
- **Caching**: Redis
- **Testing**: PHPUnit, Pest
- **Docs**: Swagger/OpenAPI (`openapi.yaml`), Laravel Scribe generated HTML docs.

## Quick Start (Local Development)
```bash
# Clone the repo (already done)
cd backend
cp .env.example .env          # edit .env as needed
composer install
php artisan key:generate
php artisan migrate --seed   # creates tables & demo data
php artisan serve            # runs at http://127.0.0.1:8000
```

## Docker / Sail
```bash
# Using Laravel Sail (Docker)
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate --seed
```
