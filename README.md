# Hotel Management System (HMS)

## 📖 Project Overview
The **Hotel Management System (HMS)** is a full‑stack web solution that lets hotel staff manage rooms, reservations, guests, billing, and reporting, while providing a public‑facing portal for guests to browse rooms, check availability, and book stays.

- **Three separate applications**:
  1. **Backend** – Laravel RESTful API (core business logic, authentication, reporting).
  2. **Admin App** – React/TypeScript UI for hotel employees.
  3. **Frontend App** – Guest‑facing React/TypeScript website.

> **Why HMS?**
> *Instantly view occupancy, revenue, and upcoming check‑ins.*
> *Staff can update room status, create invoices, and generate PDF receipts.*
> *Guests enjoy a smooth booking flow with real‑time availability.*

| **Documentation** | Swagger (l5‑swagger), Mermaid diagrams, Markdown |

## ✨ Client‑Facing Highlights
- **Real‑time occupancy dashboard** with charts for daily/weekly occupancy, ADR (average daily rate), and revenue.
- **Instant room availability** via interactive calendar – no more over‑booking.
- **Secure online payments** (Stripe) with automatic PDF receipt generation.
- **Multi‑language UI** (English + optional locales) powered by `react-i18next`.
- **Responsive design** – works on desktop, tablet, and mobile devices.
- **Email & SMS notifications** for booking confirmations, reminders, and cancellation updates.

## 💻 Getting Started (All Apps)
```bash
# Clone the monorepo (already done)
cd HMS

# ---------- Backend ----------
cd backend
cp .env.example .env   # adjust DB credentials, APP_URL, etc.
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve   # http://127.0.0.1:8000

# ---------- Admin UI ----------
cd ../admin-app
cp .env.example .env   # set VITE_API_URL to http://127.0.0.1:8000/api/v1
npm install
npm run dev          # http://localhost:5173

# ---------- Frontend UI ----------
cd ../frontend-app
cp .env.example .env   # set VITE_API_URL similarly
npm install
npm run dev          # http://localhost:5174
```

> **Tip:** Use `./vendor/bin/sail up -d` inside `backend` to spin up a full Docker environment (php‑fpm, nginx, mysql, redis) with a single command.
